# Konami 053248 CPU — measured instruction reference

Vendetta PCB specimen, September 2026. **206 observed primary encodings.**
The original baseline has 197 opcodes, 707 timing cases and 81,772 accepted
flag/result records; issue #2 adds nine encodings, with narrower coverage below.
This is a measured reference, not an exhaustive specification or an assertion
that current JTKCPU RTL matches it.

## Conventions

| Item               | Meaning                                                                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Clock              | Single 12 MHz CLK input; no E/Q pins. One CLK period ≈ 83.33 ns.                                                                           |
| CLK column         | Input-clock periods from repeated-block differential timestamp fits; **not** divided-by-four M6809 cycles.                                 |
| Timing scope       | Steady-state block measurements, not direct fetch-boundary captures; prefetch, overlap and caching remain unestablished.                   |
| Hexadecimal        | Opcodes, postbytes, masks and example register values are hexadecimal unless explicitly noted. Timing counts and formulas are decimal.     |
| Registers          | A/B: 8-bit; D=A:B: 16-bit; X/Y/U/S/PC: 16-bit; DP: 8-bit stack-visible page register.                                                      |
| CC bits            | Bit 7..0 = E, F, H, I, N, Z, V, C.                                                                                                         |
| Memory             | M8[EA] is a byte; M16[EA] is a big-endian word. Arithmetic wraps to the destination width.                                                 |
| Symbols            | `r`: result; `x`: original operand; `c`: incoming C; `sign(r)`: result MSB; `zero(r)`: result equals zero.                                 |
| Preserved flags    | `–` in flag tables means unchanged. E/F/I are preserved unless CC is explicitly changed/restored.                                          |
| Addressing         | `EA`: postbyte-addressed operand; `EXT`: postbyte 07 plus a 16-bit address.                                                                |
| EA timing          | Unless stated otherwise, an EA row's CLK count is **EXT only**; do not apply it to all postbytes.                                          |
| Conditional timing | `F/T` = condition false/true. Branch timing used displacement zero; separate outcome/flag tests used +6.                                   |
| Evidence           | [Measurement details](pcb-053248.md), [reproduction tools](../ver/pcb/README.md), [RTL discrepancy tests](../ver/top/tests/pcb/README.md). |

## Condition-code register

| Bit | Flag | Meaning                                                                      |
| --- | ---- | ---------------------------------------------------------------------------- |
| 7   | E    | Entire-state frame indicator; restored E selects RTI frame size.             |
| 6   | F    | FIRQ mask (architectural name; physical assertion timing not characterized). |
| 5   | H    | Half carry / DAA input; operation-specific output rules below.               |
| 4   | I    | IRQ mask (architectural name; physical assertion timing not characterized).  |
| 3   | N    | Negative/result sign for operations that update it.                          |
| 2   | Z    | Zero indication, with documented SEX/ROL/DAA exceptions.                     |
| 1   | V    | Signed overflow for operations that update it.                               |
| 0   | C    | Carry/borrow or shifted-out bit; operation-specific exceptions below.        |

## Instruction table

Each primary byte appears once. Immediate operands and displacements follow the
opcode; EA operands begin with a postbyte. Encodings, lengths and unresolved
addressing variants are defined below. Bytes 01, 5E–5F, AF and D2–FF remain
unresolved; a failed test sequence does not establish an illegal primary opcode.
F0/BSWI is a JTKCPU extension, not a measured physical opcode.

watchdog-wait control. This is not an instruction cycle count. Register/flag
effects (`?`) and reset-entry cycles (`—`) are unmeasured. Tested 01/D2/FF

`ENTRY` behavior (CC input presets 00/50/FF):

| ------ | ------ | ----------- | -------------- | ---------- | ------------------- |
| 02     | FFFC   | 12          | Opcode address | CC OR 80   | CC OR D0            |

measurements subtract matched handler/RTI paths using measured PSHS+JMP costs
(78 CLK for a full-frame baseline, 48 CLK for a short frame). These are raw
opcode timings, not external interrupt-pin response measurements.

Full frame order: CC,A,B,DP,X,Y,U,PC; short frame: CC,PC. S decreases by the
frame size; captured D/X/Y/U/DP are preserved. All saved fields and vector
identities were read back. 02–04 expose interrupt-entry behavior despite masked
interrupts; their saved PC would retry the opcode after an unchanged RTI frame.

- Following-instruction markers verify lengths: A,X = 2 bytes, direct = 3,
  extended = 4. Timings use repeated blocks of 0/128/256/512 instructions.

- The 59 originally missing primary bytes were each screened with four
  suffixes: AE padding, A0, C4 AE, and 07 2F 80, each followed by AE padding.

## Operand encoding and addressing

| Form                    | Bytes after opcode                        | Total instruction bytes | Interpretation                                               |
| ----------------------- | ----------------------------------------- | ----------------------: | ------------------------------------------------------------ |
| Inherent                | None                                      | 1                       | Operands implied by opcode.                                  |
| #imm8 / #count8 / mask8 | One byte                                  | 2                       | Unsigned byte; variable shift uses its low four bits.        |
| #imm16                  | High byte, low byte                       | 3                       | Big-endian word.                                             |
| rel8 / rel16            | Signed displacement, big-endian for rel16 | 2 / 3                   | Branch/call target relative to the next instruction.         |
| reg-postbyte            | One selector byte                         | 2                       | See transfer table; not the ordinary 6809 register encoding. |
| EA                      | Postbyte, then zero/one/two operand bytes | 2–4                     | Address forms below.                                         |

`R` in the postbyte table is the high-nibble code: X=2, Y=3, U=5, S=6,
PC=7. Thus `R6` means 26 for X, 36 for Y, etc. `Q=R+8` selects accumulator
offsets: X=A, Y=B, U=D, S=E, PC=F. Square brackets mean a **big-endian
16-bit pointer dereference**, not a wider final operand. LEA forms an address
rather than reading the final byte/word operand.

| Address syntax | Postbyte | Additional bytes  | Address / register effect | TST CLK | Indirect postbyte | TST indirect CLK |
| -------------- | -------- | ----------------- | ------------------------- | ------: | ----------------- | ---------------: |
| ,R             | R6       | None              | EA=R                      | 16      | RE                | 23               |
| ,R+            | R0       | None              | EA=old R; R+=1            | 16      | R8                | 23               |
| ,R++           | R1       | None              | EA=old R; R+=2            | 17      | R9                | 24               |
| ,-R            | R2       | None              | R−=1; EA=new R            | 16      | RA                | 23               |
| ,--R           | R3       | None              | R−=2; EA=new R            | 17      | RB                | 24               |
| signed8,R      | R4       | Signed byte       | EA=R+signed8              | 21      | RC                | 28               |
| signed16,R     | R5       | Signed word       | EA=R+signed16             | 22      | RD                | 29               |
| A,R            | Q0       | None              | EA=R+signed A             | 18      | Q8                | 25               |
| B,R            | Q1       | None              | EA=R+signed B             | 18      | Q9                | 25               |
| D,R            | Q7       | None              | EA=R+D, modulo 65536      | 20      | QF                | 27               |

## Stack masks, frame layout and timing

| Mask bit | Value | Register                                           | Bytes |
| -------- | ----- | -------------------------------------------------- | ----: |
| 0        | 01    | CC                                                 | 1     |
| 1        | 02    | A                                                  | 1     |
| 2        | 04    | B                                                  | 1     |
| 3        | 08    | DP                                                 | 1     |
| 4        | 10    | X                                                  | 2     |
| 5        | 20    | Y                                                  | 2     |
| 6        | 40    | U for S-stack operations; S for U-stack operations | 2     |
| 7        | 80    | PC                                                 | 2     |

Push decrements the selected stack pointer; pull increments it. At ascending
frame addresses, selected fields occur in the order **CC,A,B,DP,X,Y,other-SP,PC**;
words are high-byte first. Pushed PC is the next opcode address. Pulling PC
branches to the restored address. Pulling CC replaces all its bits.

| Operation               | Measured CLK formula / value                                                      |
| ----------------------- | --------------------------------------------------------------------------------- |
| PUSHS / PUSHU           | `21 + 3b + 7w`; b=selected byte registers, w=selected word registers including PC |
| PULLS / PULLU           | `20 + 4b + 8w + 7p`; w excludes PC; p=1 if PC selected, otherwise 0               |
| Empty push / pull       | 21 / 20                                                                           |
| Full FF push / pull     | 61 / 67                                                                           |
| Pull PC only            | 27                                                                                |
| Pull 7F (all except PC) | 60                                                                                |
| RTS                     | Pull PC; 2 bytes; 14 CLK                                                          |
| RTI, restored E=0       | CC,PC; 3 bytes; 21 CLK                                                            |
| RTI, restored E=1       | CC,A,B,DP,X,Y,U,PC; 12 bytes; 63 CLK                                              |

RTI frame size is selected by the **restored** E bit, even when incoming E is
opposite. Full-frame D/X/Y/U restoration is verified; DP frame byte was 00
and its restoration was not independently measured. Formulas fit empty,
single-register and tested composite masks; the complete 256-mask space was
not measured.

## Transfer selector behavior: 3E / 3F

Postbyte=`(destination<<4)+source`. **Both opcodes exchange values** for all
ordered selector pairs 0..5 tested. Read both source values before the writes.
Flags and S are preserved. `3F` retains the historical assembler name TFR in
other sources, but a one-way-copy interpretation is wrong for these encodings.

| Selector                      | Value read              | Destination written                                 |
| ----------------------------- | ----------------------- | --------------------------------------------------- |
| 0                             | B:A word                | A receives low byte                                 |
| 1                             | A:B word                | B receives low byte                                 |
| 2                             | X                       | X receives word                                     |
| 3                             | Y                       | Y receives word                                     |
| 4                             | DP-related 16-bit value | Word updated; high byte exposed by DP stack capture |
| 5                             | U                       | U receives word                                     |
| 6 / 7 and other postbyte bits | Unmeasured              | Do not assume a register assignment                 |

Selector 4 is **not S** in the measured forms. Seeding it with A67B and
exchanging it with a word register returns the whole A67B, although PSHS DP
exposes only A6. All 36 ordered pairs per opcode take 8 CLK in the tested
repeated sequences. Eight additional fixed-instruction probes confirm four
pairs across twelve seed patterns and eight CC presets.
